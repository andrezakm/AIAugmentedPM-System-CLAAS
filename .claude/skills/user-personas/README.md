# User Personas

Verdichtet Discovery-Belege oder Schreibtisch-/Web-Recherche zu 1–3 evidenzbasierten Personas — jede Aussage als Beleg oder markierte Annahme. Der Wert liegt in der Disziplin, nicht in der Behauptung, "die richtige" Persona gefunden zu haben.

## Input

Zwei Modi, auch kombinierbar:

- **Modus A — Primärbelege** (höhere Konfidenz): vorhandene Discovery-Outputs, z. B. `output/YYYY-MM-DD/discovery/feedback-clusters.md`, Interview-Synthesen
- **Modus B — Schreibtisch-/Web-Recherche** (niedrigere Konfidenz, ehrlich so markiert): öffentliche Quellen zur Zielgruppe, wenn (noch) keine eigenen Interviews vorliegen

## Invocation

`/user-personas`

## Output

`output/YYYY-MM-DD/discovery/personas.md` (das mitgelieferte Beispiel liegt fest unter `output/discovery/personas-beispiel.md`)

## Weiter mit

`/opportunity-scorer` — Cluster gegen die Personas legen, bevor du bewertest.
