# Roadmap

Planen: In welcher Reihenfolge, mit wem?

- `/roadmap-intake` — rohe Stakeholder-Anfrage → Vollständigkeits-Check: entweder mit konkreten Schärfungs-Hinweisen zurück oder als Kandidat aufgenommen. Der Türsteher vor dem PM; ab „Aufgenommen" folgt der menschliche Schritt (Termin mit dem PM).
- `/product-roadmap` — aufgenommene, priorisierte Ideen → sequenzierte Roadmap (Now / Next / Later, alternativ Timeline). Sequenziert nur — bewertet nicht neu (das macht der opportunity-scorer).

→ Ausführbar unter `.claude/skills/[name]/`. Diese Datei bildet nur die Gliederung ab.

**Ablageort:** Die Roadmap ist *lebender Zustand*, kein Lauf-Artefakt — sie liegt stabil unter `output/roadmap/` (nicht im datierten Run-Ordner), analog zum system-auditor unter `output/meta/`. Eine Anbindung an Linear/Jira/Notion für Sichtbarkeit bleibt ein optionaler Erweiterungspunkt.
