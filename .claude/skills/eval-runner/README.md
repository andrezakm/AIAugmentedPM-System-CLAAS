# Eval Runner

Eval + Prototyp (`app.html` + `data.js`) → PASS / FAIL / UNKLAR pro Kriterium, mit Begründung aus Code und angezeigtem Verhalten.

## Input
`output/YYYY-MM-DD/spec-eval/eval.md` + `output/YYYY-MM-DD/prototyping/app.html` (oder option-a/b/c)

## Invocation
`/eval-runner`
Mit expliziten Pfaden: `/eval-runner output/YYYY-MM-DD/spec-eval/eval.md output/YYYY-MM-DD/prototyping/option-b/app.html`

## Output
`output/YYYY-MM-DD/prototyping/eval-results.md`
