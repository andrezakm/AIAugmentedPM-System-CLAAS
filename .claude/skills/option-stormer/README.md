# Option Stormer

Spec → 3 strukturell verschiedene Zero-Install-HTML-Prototypen + Vergleichstabelle.

Der Willison-Move: nicht eine Lösung bauen und hoffen — drei Richtungen prototypen, weil es fast nichts kostet, dann entscheiden. Fällt eine Variante durch die Eval, lohnt sich trotzdem die Frage: welche Prinzipien funktionieren? Rekombination führt oft zu besseren Ergebnissen als Iteration.

## Input
`output/YYYY-MM-DD/spec-eval/spec.md`

## Invocation
`/option-stormer`

## Output
- `output/YYYY-MM-DD/prototyping/option-a/app.html` + `data.js`
- `output/YYYY-MM-DD/prototyping/option-b/app.html` + `data.js`
- `output/YYYY-MM-DD/prototyping/option-c/app.html` + `data.js`
- `output/YYYY-MM-DD/prototyping/option-comparison.md`
