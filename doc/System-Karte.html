das gemeinsame Fundament

Was aus Skills ein System macht.

Jeder Skill liest zuerst den Kontext — deshalb ziehen alle am selben Strang statt in vierzehn Richtungen. Ein Bootstrapped-Startup bekommt andere Empfehlungen als ein Series-B-Unternehmen, ohne dass man es jedem Skill einzeln sagt.
